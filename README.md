# Restaurante Zorzi

Projeto de site de restaurante desenvolvido com foco em responsividade, organização visual e aplicação prática de conceitos importantes do desenvolvimento front-end.

O site foi construído utilizando HTML, CSS e JavaScript, com maior foco na estruturação visual e estilização da interface.

---

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

---

## Conceitos e recursos aplicados

- Flexbox
- CSS Grid
- Media Queries
- Responsividade para diferentes dispositivos
- Navegação entre páginas
- Menu hambúrguer
- Efeito Parallax
- Organização de layouts
- Paleta de cores consistente
- Tabelas e listas
- Uso de imagens

---

## Estrutura do projeto

O projeto possui múltiplas páginas organizadas, incluindo:

- Página inicial
- Página Home
- Página de comidas
- Página de bebidas
- Página de estatísticas

Além disso, o projeto conta com:

- Arquivos CSS separados
- JavaScript para interações da interface
- Organização modular das pastas
- Recursos visuais personalizados

---

## Funcionalidades

- Navegação entre páginas
- Layout responsivo
- Menu responsivo para dispositivos móveis
- Sessões organizadas para comidas e bebidas
- Estatísticas visuais
- Adaptação para diferentes tamanhos de tela
